# Netflix Content Analysis Dashboard
The dashboard provides a comprehensive overview of content distribution between Movies and TV Shows.

# Project Objective
To analyze Netflix's content library and uncover insights into content distribution, genre popularity, content ratings, geographical presence, and growth trends over time. The dashboard helps users understand Netflix's content strategy by providing interactive visualizations of movies, TV shows, genres, ratings, countries, and release-year trends.

# Key Visualizations
Movies vs TV Shows Distribution (Pie Chart)
Content by Rating (Bar Chart)
Genre Distribution Analysis (Bar Chart)
Content Growth by Release Year (Area Chart)
Country-wise Content Distribution (Treemap)
